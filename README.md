## ✨ Features

- **Core Metrics**: Instantly calculates BMI, healthy weight ranges, BMR, and TDEE.
- **Smart Macros**: Generates daily Carb, Protein, and Fat targets based on your profile.
- **Goal Planning**: Provides exact caloric adjustments for **Maintenance**, **Fat Loss** (-500 kcal), and **Muscle Gain** (+500 kcal).
- **Diet Modes**: Switch seamlessly between *Standard* and *Low-Carb* macro splits.
- **Clean UI**: Modern, scrollable, and user-friendly Tkinter interface with tooltips.
